# OpenLexicon

OpenLexicon stewards open vocabularies, schemas, and interoperability contracts
for infrastructure and emergency systems.

## Projects

- **CEL** — speakable incident and response vocabulary.
- **OIDF** — open infrastructure deployment and commissioning format.

## Boundary

OpenLexicon publishes formats and reference tooling. It does not operate feed
ingestors, decide consumer policy, control equipment, or sell deployment
services.

## Contribute

Start with the repository's `CONTRIBUTING.md`, `GOVERNANCE.md`, and RFC process.
Semantic changes require source provenance, compatibility notes, validation, and
maintainer review.

## Related company

EnoTech may build commercial products and services that implement or consume
OpenLexicon projects. OpenLexicon remains the public project/community layer.
